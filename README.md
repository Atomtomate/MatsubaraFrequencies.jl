# MatsubaraFrequencies

[![Build Status](https://github.com/Atomtomate/MatsubaraFrequencies.jl/actions/workflows/CI.yml/badge.svg?branch=master)](https://github.com/Atomtomate/MatsubaraFrequencies.jl/actions/workflows/CI.yml?query=branch%3Amaster)

Minimalistic type system for Matsubara frequency indices.
This should be zero overhead, but is not benchmarked at the moment.

See [MatsubaraFunctions.jl](https://github.com/dominikkiese/MatsubaraFunctions.jl) if you require anything more than pure indices.
